Irris follows the SOP with you, flags a deviation the moment it happens and writes the batch record as you work.

SOP-114 · Cover assemblyRev C
  1. Isolate power and lock out
  2. Fit gasket G-12, lip facing out
  3. Place cover on the dowels
  4. Torque bolts to 12 N·m (11.5–12.5)
  5. Leak test at 2 bar for 60 s
  6. Label with the batch number
  7. Photograph and sign off

    API and MCP

    Built for developers

    A REST API and an MCP server. Your agents get the same twin your team does.

    irr_ key 
    # Send anything
$ curl $IRRIS_URL/api/v1/ingest \
    -H "Authorization: Bearer $IRRIS_KEY" \
    -d '{"type":"event","subject":"asset:press-7","text":"E-stop on cycle 4410"}'

# Ask about it
$ curl $IRRIS_URL/api/v1/ask \
    -H "Authorization: Bearer $IRRIS_KEY" \
    -d '{"message":"Why did press 7 stop this morning?"}'
